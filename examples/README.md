# 可直接查看的原权重预测示例

E0、E1、E2各目录包含case 16最后一帧的预测NPZ、ParaView VTU/PVD，以及位移、等效应变、等效应力三张对比图。

这些是**原论文训练权重在完整粒子数据上的实际推理**，不是快速流程测试训练出来的结果。图中包含真值、预测及绝对误差，单位与原论文一致。`metrics.json`记录本帧指标。

这只是一个便于打开检查的示例，不代表全部验证集、测试集或末端区间汇总。完整输出请在图形界面选择所需集合并预测。程序默认的Final汇总阈值为s≥0.999，case 16包含最后两帧；本目录仅保留最后一帧供预览。

ParaView打开各目录的 `case16_final.pvd` 或 `case16_final.vtu` 即可。模型预测几何的显示方式见项目主说明。
