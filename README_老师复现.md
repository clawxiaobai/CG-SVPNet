# CG-SVPNet 五通道 E0 / E1 / E2 复现项目

本项目对应闭式锻造中的五通道并列预测：三个位移分量、等效应变和等效应力。数据、训练/验证/测试划分、模型超参数、损失及评价口径沿用作者现有实验。它不是五个物理模型的混合，也不包含后续冻结位移双分支或E5门控实验。

## 1. 打开程序

在已配置好的本机，双击 **`启动程序.vbs`**（无控制台窗口），或 **`launch.cmd`**。

换到老师电脑时：

1. 复制整个项目目录，**必须包含 `data/closed_die/` 和 `pretrained/`**。数据是真实独立副本，不是指向作者机器的快捷方式。
2. 安装64位 Python 3.13.x，安装时保留 Tcl/Tk 并加入 PATH。依赖锁按Python 3.13验收；本机原实验解释器为3.13.0。
3. 不要迁移作者机器上的 `.venv/`；虚拟环境不可跨电脑直接复用。双击 `setup_environment.cmd` 在老师电脑创建项目内环境。需要联网下载PyTorch等依赖。
4. 双击 `launch.cmd`。如启动失败，查看 `startup_error.log`。CUDA不可用时可以CPU运行，但完整训练会明显变慢。

若误复制了作者的 `.venv/`，请先将该目录重命名保留，再运行环境安装。启动器要求项目内环境，不会自动借用未经验证的全局Python环境。

推荐 NVIDIA CUDA GPU；作者原硬件为 RTX 4060 8 GB。完整训练可能耗时较长。训练、全粒子预测和文件导出是三个不同阶段；模型前向耗时不包括数据载入、绘图及写文件。

安装入口使用 [PyTorch 官方历史版本安装说明](https://pytorch.org/get-started/previous-versions/) 中的 PyTorch 2.7.1 / CUDA 11.8。为简化部署，本项目不依赖 spconv、torch-scatter、torch-cluster、ParaView Python模块；二值占据计数改用PyTorch原生 `index_add_`，其等价性检查见 `qa/kernel_equivalence.json`。

## 2. 界面操作

1. **选择数据**：默认选中项目 `data/closed_die`，类型为“整套数据包根目录”。若直接选择 `processed_mpm`，类型改为“直接选择 processed_mpm 目录”，其旁边必须有同名surface、geometry辅助目录。此版本只支持原闭式锻造五通道预处理NPZ结构，不把任意VTU当作可直接训练的数据。
2. **检查数据**：核对21个算例、字段、模具接触资产、辅助文件、划分和目标状态数。勾选完整SHA-256可进一步验证数据内容与交付清单一致。
3. **选择 E0、E1 或 E2**：论文模式锁定原参数；没有随机重划分、修改损失权重或自动调参。
4. **开始训练 → 自动预测**：新建时间戳结果目录，不覆盖旧实验。查看日志、当前轮次/批次、加权损失和三种验证误差曲线。最佳权重只由验证集选取。
5. **训练后自动导出**：默认导出验证集的全部75个目标状态；也可以选论文测试集的74个状态或两者。支持NPZ、VTU或两种格式。
6. **预测截面图**：选择具体算例/时间步，再切换位移、应变、应力。图中真值、预测值、误差使用同一色标；三张面板使用相同坐标比例。

“快速流程测试”只做小网格、小采样的一轮训练，用于验证安装和软件流程，输出会明确标记为smoke，**不能当作论文精度结果**。

“安全停止”在批次或状态边界生效，当前写文件可能需要等一会儿。已生成的完整文件和最近保存的最佳模型保留。GUI支持“从断点继续训练”，并将续训写入新的运行目录；直接开始新训练则从头初始化，不与连续训练混同。

## 3. 先复核现有权重，再从头训练

附带三个原实验最佳权重，点击“使用原论文权重预测”，选择“测试集：05 / 16 / 17”及论文设置，可直接得到本项目对同一测试数据的预测。

原五通道实验的全测试集汇总值（来自各模型 `final_metrics.json`）：

| 模型 | 位移分量 RMSE (mm) | 等效应变 RMSE | 等效应力 RMSE (MPa) | 最佳轮次 |
|---|---:|---:|---:|---:|
| E0 | 0.14425288 | 0.06927041 | 1.92186827 | 368 |
| E1 | 0.13717735 | 0.06161783 | 1.85552034 | 318 |
| E2 | 0.12388306 | 0.06157837 | 1.80479827 | 404 |

位移分量RMSE是对三个分量平方误差汇总再开方，不等于位移误差向量模长的RMSE。应变无量纲，应力MPa。对照位置为 `pretrained/<模型>/final_metrics.json`；验证集数值不同，不要拿验证集与上表测试集直接比较。

原指标 `Final` 是 `s ≥ 0.999` 的末端区间，可能包含多帧；例如case 16最后两帧均满足条件。程序保持这个定义，并另列每帧指标，不能把最后一帧误差直接拿来核对末端区间汇总。

不同硬件、GPU归约和软件环境可能产生浮点或训练优化差异。固定随机种子和协议用于可比复现，不保证任意硬件重新训练后每个浮点数都相同。随附权重推理可先验证数据和模型实现；完整重新训练是另一项检验。

## 4. 文件输出

每次运行都在 `runs/` 或所选输出目录新建一个实验目录：

```text
request.json / environment.json / data_check.json
worker.log / status.json
config.json / train_log.csv                  # 训练任务
best_model.pth / checkpoint_latest.pth       # 训练任务
final_metrics.json                          # 原口径的验证/测试汇总
predictions/
  val/ 或 test/
    metrics.csv / summary.json
    case_XX/
      step_XXXXXX.npz
      step_XXXXXX.vtu
      sequence.pvd
      step_XXXXXX/
        displacement.png/.pdf
        strain.png/.pdf
        stress.png/.pdf
```

NPZ包含初始位置、参考位置、预测位置、位移真值与预测值、等效应变/应力真值与预测值、原数组行索引及目标状态信息。不降采样导出论文模式的粒子数据。`particle_row_id`是保留的原NPZ行索引，不冒充求解器另行定义的材料点ID。

`target_frame_index` / `target_step`和CSV的`step`指预处理文件序号；`solver_step_id`另存原求解器步号。`summary.json`包含总体、后期、末端区间及分算例指标。

每个验证或测试集合建议预留 **至少20 GB** 输出空间；如果同时导出两者，建议至少40 GB。精确需求随NPZ压缩率、粒子数和输出格式变化。原始数据包约38.72 GB，另需环境、权重和输出空间。

## 5. ParaView 查看

### 训练界面与时间步浏览（界面修订）

- 损失图显示日志记录的批次损失和每轮平均损失；验证误差只在完成验证后出现。论文设置在第1轮、此后每2轮验证一次，未验证的轮次不补造数据。单个数据点也会显示。
- 预测页通过“集合 / 算例”和“时间步”选择结果，支持上一/下一步、位移/等效应变/等效应力切换；按窗口大小等比例缩放图片。时间步为预处理帧序号，原求解器步号和进度另列。
- 完整训练结束后才自动导出预测。尚未导出时会明确显示为空，不再沿用前次快速测试图片。快速测试仅有稀疏采样和少量状态，其图片不代表完整模型效果。
- 训练期间可以“打开已有结果”浏览其他运行；不会改变当前训练、停止按钮作用的目录或训练曲线来源。“本次运行结果”返回本次预测。
- 已打开的旧界面不会自动更新代码。训练期间双击 `查看训练进度.vbs`，可在新版只读窗口中查看最近一次训练日志和浏览结果，**不重启、不停止训练**。关闭该只读窗口也不影响训练；旧窗口仍负责原训练进程，请勿在旧窗口确认停止。
- 监视指定运行可执行 `.venv\Scripts\python.exe app.py --attach runs\训练目录名`。只读窗口禁用启动训练和停止按钮，避免重复任务。
- 训练意外中断后，点击“从断点继续训练…”并选择原运行目录中的 `checkpoint_latest.pth`。程序从下一轮继续，同时继承优化器、学习率调度、最佳模型、训练日志和早停计数；续训写入新的运行目录，不覆盖原运行。

### ParaView 操作

1. 在ParaView打开某算例的 `sequence.pvd`，点击Apply；它包含所有已导出状态，时间值为目标进度 `s`。
2. 使用Points或Point Gaussian显示粒子。选择 `equivalent_stress_prediction_MPa`、`equivalent_strain_prediction` 或位移模长着色。
3. 参考字段和绝对误差字段一起保存在同一个VTU内，可直接切换比较。
4. VTU默认几何为**参考材料点位置**。要显示预测变形形状，添加Warp By Vector，向量选 `prediction_minus_reference_position_mm`，Scale Factor设1。不要再用完整预测位移重复移动已经变形的参考坐标。
5. 做Slice可获得截面；程序预览使用参考位置 `|y| ≤ 2.5 mm` 的材料点薄层。颜色范围默认每个物理量、每个状态按真值/预测/误差的可见最大值共享，不默认跨所有时间步统一；跨时间比较时在ParaView手动统一范围。

## 6. 核心文件与方法

- `forging/model.py`：E0/E1/E2实际使用的五通道模型，保持原权重键与初始化路径兼容。内部保留少量原类分支仅为可追溯，不向界面开放其他模型。
- `forging/components.py`：网格U-Net、接触场查询和网格—材料点采样。
- `forging/dataset.py`：原数据处理和采样实现。
- `forging/protocol.py`：原采样参数、归一化、批次映射及指标累计。
- `forging/trainer.py`：原损失、优化、验证和选择过程，增加独立输出路径、进度和安全停止钩子。
- `forging/prediction.py`、`forging/vtk_io.py`：预测、指标、截面图和VTU/PVD导出。
- `forging/gui.py`：桌面界面，不包含模型计算。
- `docs/METHOD.md`：模型、损失和数据划分的详细说明。

本次整理不修改论文或原工作区，也未重新执行三个模型完整500轮训练。具体软件验收范围以 `qa/` 下实际记录为准。
