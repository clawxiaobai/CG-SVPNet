# 五通道方法与复现协议

## 问题与数据

输入为初始材料点构型及目标冲头条件，输出同一材料点的三维位移、等效应变和等效应力。每个目标状态独立查询，不将预测结果回馈到下一时间步。目标应力/应变只用于监督，不能作为输入。

训练集：01、02、03、04、07、08、10、11、12、13、14、18、19、20、21。

验证集：09、06、15。测试集：05、16、17。默认有效目标状态数依次为370、75、74。

各case元数据保留原 `world_center`、`world_scale`、模具平移和时间步映射；数据复制不重建坐标包围盒，不重采样粒子，不重写数值。原数据工作域元信息来自既有预处理；整理不能被解释为改变了原工作域定义。

归一化位置为 `(x - world_center) / (world_scale / 2)`；位移除以相同半尺度。等效应变乘0.2，应力乘0.02进入监督，评价时除回对应乘数。应力原量单位MPa。

## 共享特征网格

41通道：二值占据1通道 + 固定下模11通道 + 初始冲头11通道 + 目标冲头11通道 + 初始/目标平移各3通道 + 进度1通道。

接触资产使用原 `*_contact_asset.npz`；距离通道优先取其中 `distance`，其余梯度、曲率等通道原样查询。不把开放模具表面的旧SDF误当作当前接触距离。

规则网格64³，3D U-Net宽度24，四级通道24/48/96/192。编码、采样轴顺序、三线性插值、`align_corners=True` 与原实现一致。

## 三种解码方式

E0：U-Net直接生成5通道网格，三线性插值得到材料点输出。

E1：U-Net生成96通道隐特征。材料点查询输入为插值隐特征、初始归一化位置和目标进度，经两层128宽SiLU隐层后输出5通道。

E2：在E1输入中加入局部亚体素坐标 `xi`、`xi²`、`sin(pi*xi)`、`cos(pi*xi)`。其中 `q=(x_norm+1)(R-1)/2`，`xi=q-clamp(floor(q),0,R-2)-0.5`。这不是把整个位移回归网络改成应力或应变专用网络。

三种模型输出前3通道为位移，后2通道经softplus得到非负的归一化应变与应力。状态初值0.05。为与已有权重及从头初始化一致，保留原模型初始化时的随机数消耗顺序。

## 损失与选择

记三个归一化RMSE为Ru、Re、Rs，目标进度为s：

`L = (1 + 2*s^8) * (100*Ru + 5*Re + Rs)`。

RMSE开方前加 `1e-12`。不存在本项目新增的自动损失平衡算法。采用AdamW，学习率1e-4，权重衰减1e-4，梯度范数裁剪1.0；500轮余弦退火至学习率5e-6。CUDA训练使用与原代码相同的bfloat16自动混合精度；评价使用原FP32路径。

固定随机种子20260805，batch size=1。每状态最多采样300000点，原 `all_surface_deformation` 采样函数与参数保留；训练jitter=0.04，验证/测试jitter=0，评估max_points=None（全粒子）。不能把快速流程测试的2048点结果混入论文评价。

第一轮及之后每两轮验证，80轮无改善早停。设某时段的组合误差为：

`S = displacement_RMSE_mm + 0.5*(0.2*strain_RMSE + 0.02*stress_RMSE_MPa)`。

最佳模型按 `S_all + 0.35*S_late + 0.35*S_final` 选择，后期s≥0.70，末态s≥0.999。只使用验证集选模，测试集仅在训练结束后评价。默认GUI在训练后还为验证集导出全量预测；预测范围可由用户改为测试集或两者。

## 实现核对与原始证据

`reference/source_provenance.json`记录抽取来源与源文件哈希。核心类/函数从原文件抽取，参数配置和三个最佳权重直接复制。为去除非核心编译扩展，仅将本路径使用的占据计数scatter-add换成原生PyTorch，原二值占据不变。

作者侧已在旧环境检查三个模型的同种子初始化、前向值、损失及梯度，记录见 `qa/kernel_equivalence.json`。该检查不是对全部测试状态或完整重新训练的重复。读者不需要旧工作区即可运行主程序和 `tests/test_unit.py`。原数据的逐文件SHA-256清单见 `data/dataset_manifest.json`；原权重及数据下载包的校验值见 `release_manifest.json`。

归档的精度是参考实验结果，不是对任意重新训练结果的承诺。完整重新训练的结果必须从该次 `final_metrics.json` 读取，不能复制参考值伪装成本次运行结果。
