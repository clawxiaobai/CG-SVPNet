# 独立闭式锻造数据

`closed_die/`包含作者原始预处理数据的独立副本：

- `processed_mpm/`：21个算例的全部NPZ时间步、JSON元数据及模具/接触场资产。
- `processed_mpm_surface/`：21个算例的原表面索引与表面数据。
- `processed_mpm_geometry/`：21个算例的原坯料几何辅助数据。
- `dataset_manifest.json`：1284个文件的相对路径、字节数及SHA-256。

完整大小为38,721,671,791字节（约38.72 GB，十进制）。所有原文件均逐字节校验，未重算、压缩改写、抽样或重新划分。

界面中选择本目录下的 `closed_die`，目录类型选择“整套数据包根目录”。不要只复制 `processed_mpm` 而遗漏其他两个目录。元数据中的原始VTU历史路径保留作溯源记录，训练/预测直接读取本包的预处理文件，不需要访问这些旧VTU路径。

本数据集是现有闭式锻造任务，不能将独立平砧镦粗数据直接改名混入。图形界面支持的数据结构固定，不能直接读取任意CSV或原始VTU作为训练输入。
